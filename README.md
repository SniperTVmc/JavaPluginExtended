# JavaPluginExtended
A lightweight, optimized, and easy-to-use Bukkit/Paper/Bungeecord/Velocity framework with a large collection of methods ready to use in your plugins.

### Why use JavaPluginExtended?

- **Lightweight and Optimized**: Designed to minimize resource usage while maximizing performance.
- **Easy to Use**: Simple API that allows developers to quickly integrate and utilize the framework in their projects.
- **Comprehensive Method Collection**: A wide range of pre-built methods to handle common tasks in plugin development.
- **Cross-Platform Support**: Compatible with Bukkit, Paper, Bungeecord, and Velocity, making it versatile for different server types.
